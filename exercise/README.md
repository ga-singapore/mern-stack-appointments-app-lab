## Overview

In this lab, you'll build a MERN stack app, where your front-end is built using React and your back-end uses Express for the API layer and Mongodb as the database.

## Prerequisites

- React (unit 2)
- Intro to Express
- Express routers & controllers
- Intro to Mongodb
- Intro to Mongoose

## User Requirements

- As A User (AAU) I would like to able to store all appointments that I have regardless of interviews with clients, lunch with friends, medical appointments for family members.
- AAU, I would like to be able to add new appointments into the app, so that I can all my appointments are up to date.
- AAU, I would like to be able to see a brief version of all appointments and if I need too to, to be able to see all the details of a single appointment.
- AAU, I would like to be able to delete any appointments so that I can remove any appointment that has been cancelled.
- AAU, I would like to be able to update any appointment so that I can change any details pertaining to that appointment, whether a change of date/time, address, etc.

## App Requirements

You have complete creative freedom to design the look and feel of the app, how the APIs behave and the design of the database. You can determine the number and functionality of the APIs, and implementing JWT and login is not necessary.

This is a personal app for users to track their appointments, so authentication and authorisation is not required. The app should support full CRUD operations and store the following minimum fields:

- Title/Label (of the appointment)
- Type (e.g., interviews, medical, dental, lunch, dinner, etc.)
- Purpose (e.g., meet to change deliverables)
- Company (where the appointment is held)
- Person meeting with
- Address (of the company)
- Date and Time (can be stored together or separately)
- Comments (text box)

You can choose the titles for the input fields, and it is up to your discretion to decide which fields are optional. You can also add more fields if you deem it is required

## Main Objective

In this lab, you will build a full stack app so that you'll be able to understand how the front and backends work in concert to deliver what is required.
